# Launcher icon variants (KPF-0019 / KPF-0020)

KidPlay ships exactly two predeclared launcher variants: **Fox Heart** (the safe default) and **Sunshine**. The default Fox Heart variant retains the backwards-compatible `teal` wire value and alias component name so existing settings continue to decode safely, while the visible option now uses the Nano Banana `08_fox_heart.jpg` master. The Sunshine variant remains available as the existing optional alternate. The Fox Heart master is stored byte-for-byte in `app/src/main/res/drawable-nodpi/`; provenance, hash, representative colors, and QA status are recorded in `docs/assets/launcher-icon-assets.json`. The adaptive-icon XML files only describe Android runtime presentation and do not rewrite the master.

Android does not provide an API to recolor arbitrary launcher icons. Settings therefore switches between predeclared `activity-alias` components. The requested alias is enabled before the old alias is disabled, package-manager exceptions are contained, and a partial failure attempts to restore the previously launchable alias. A preference is persisted only after a successful or already-applied switch, independently of timer, activity-duration, and app-theme keys. On later launches the persisted choice is reconciled idempotently.

A successful switch leaves exactly one launcher alias enabled. Fox Heart is enabled in the manifest by default, so fresh installs and upgrades retain a safe launchable entry without adding permissions. Launcher icon refresh timing and cache invalidation are controlled by the device launcher: a new icon may appear immediately, after returning home, or only after the launcher refreshes its cache. KidPlay cannot guarantee or force that refresh.

The Fox Heart master passed the project visual QA review for centered composition, launcher-scale readability, clean subject separation, absence of visible text or watermarks, and no obvious rendering defects. This is visual QA evidence, not formal legal trademark clearance; conduct a trademark search before broad commercial launch if required. The prior K/P master remains in repository history but is no longer the active default icon.
